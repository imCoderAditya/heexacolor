## 1.0.0

- 🎉 **Major Release**: Transformed package into ThemeVerse — AI-Powered Design System Engine & Universal Color Suite for Flutter.
- 🎨 **Universal Color Engine**: Added parsing for Hex, RGB, RGBA, HSL, HSLA, HSV, CMYK, LAB, OKLAB, 140+ CSS Names, and Tailwind Colors.
- 🤖 **AI Theme & Mood Generator**: Added `ThemeVerse.generate()`, `ThemeVerse.fromMood()`, `ThemeVerse.fromSeed()`, and `ThemeVerse.fromBrand()`.
- ♿ **WCAG 2.1 & APCA Accessibility Engine**: Added contrast ratio calculation, WCAG AA/AAA verification, APCA scoring, and text color recommendations.
- 💎 **Glassmorphism & GPU Gradients Engine**: Added `GlassContainer`, `GlassDecoration`, Aurora, Metallic, and Mesh gradients.
- 🎨 **Color Harmonies & Palettes**: Added Complementary, Analogous, Triadic, Tetradic, Monochromatic, Tints, Shades, and Tones generators.
- ⚙️ **Smart Derived States**: Added automatic hover, pressed, disabled, selected, border, and shadow state colors.
- 📤 **Design Token Exporter**: Added token exports to CSS Custom Properties, Tailwind Config, JSON, and Figma Tokens.
- 🛠️ **In-App DevTools & Live Builder**: Added `LiveThemeBuilder` and `ThemeVerseDevTools` widgets.
- 🔒 **100% Backward Compatibility**: Maintained full compatibility with legacy `HexColor` class.
